# المرحلة 0 — تجميد النسخة الحالية (يوم واحد)

قبل أي تطوير جديد:

### 1. عمل نسخة آمنة

```bash
git status
git add .
git commit -m "GEN ERA Stable Commerce Build"
git push origin develop
```

### 2. إنشاء فرع جديد

```bash
git checkout -b universe-phase-1
```

الهدف:

* الحفاظ على نسخة المتجر الحالية.
* إمكانية الرجوع للخلف في أي لحظة.
