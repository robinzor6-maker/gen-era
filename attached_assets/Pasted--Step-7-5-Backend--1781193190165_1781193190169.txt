* NFC
* Collectibles
* AR
* Character Unlocks

قبل إنهاء **Temple Commerce Layer** بالكامل.

# الترتيب الاحترافي الصحيح الآن

## ✅ Step 8.0 — Temple Commerce Foundation

الهدف:

تحويل الـ Temple الموجود حالياً من مجرد مشهد بصري إلى نظام تجارة فعلي.

## المرحلة A

### Temple Product Engine

إنشاء:

```bash
src/store/templeStore.ts
```

```ts
selectedProduct
focusedProduct
panelOpen
chamberOpen
```

## المرحلة B

### API Integration

```bash
src/hooks/useTempleProducts.ts
```

```ts
GET /api/v1/products
```

## المرحلة D

> **Build Step 8.0 — Temple Commerce Foundation (Phase A + B only)**
