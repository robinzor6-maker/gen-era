# 3. ⚡ PAYMENT ROUTER (أهم جزء)

بدل ما تختار Stripe أو Paymob في كل مكان…

هنعمل **طبقة ذكية واحدة**

---

## 📁 `payment/PaymentRouter.ts`

```ts
export class PaymentRouter {
  static async createPayment(order, userLocation) {
    
    const provider = this.selectProvider(userLocation);

    if (provider === "stripe") {
      return StripeService.createCheckout(order);
    }

    if (provider === "paymob") {
      return PaymobService.initiatePayment(order);
    }

    throw new Error("No payment provider available");
  }

  static selectProvider(location: string) {
    // logic:
    if (location === "EG") return "paymob";
    return "stripe";
  }
}
```

# 4. 🧠 CHECKOUT ORCHESTRATOR (عقل النظام)

## 📁 `checkout/CheckoutService.ts`

```ts
export class CheckoutService {
  
  static async createCheckout(userId, cart) {

    // 1. Create Order
    const order = await OrderModel.create({
      userId,
      status: "CREATED",
      totalAmount: cart.total,
    });

    // 2. Add items
    await OrderItemsModel.insertMany(order.id, cart.items);

    // 3. Move to payment
    await OrderModel.update(order.id, {
      status: "PENDING_PAYMENT"
    });

    // 4. Call payment router
    const paymentSession = await PaymentRouter.createPayment(order);

    return {
      order,
      paymentSession
    };
  }
}
```
